# Compact Rotation Speed Controller (NeoForge 1.21.1, Create)

One-block speed controller. Shaft in on one side, out on the other, like a clutch.
Right click: +10% speed. Shift + right click: -10%. Range -200% to +200%.

Build: put the folder in a NeoForge 1.21.1 MDK project, or run `gradle build`.
Requires Create 6.x for NeoForge 1.21.1. Check the version in gradle.properties.
